# CRUD Netflix (filmes)

Projeto desenvolvido em Python para a disciplina de Algoritmos e Programação e documentado para a disciplina de Gestão Ágil de Projetos

## Objetivo

Este projeto pretende organizar as informações de filmes por meio de um CRUD.

## Tipos de Dados

- Nome: string
- Duração em minutos: int
- Gênero: string
- Sinopse: string
- Ano: int
- Nota: float

## Funcionalidades

- Cadastrar filmes
- Listar filmes
- Atualizar filmes
- Excluir filmes
